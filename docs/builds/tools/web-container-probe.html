Web engine container probe — MoviesTv-Flix

Static page, no build step: serve the folder with any HTTP server (for example python3 -m http.server 8781) and open it on the device or browser you want to measure. It reports canPlayType answers and then attempts real Matroska and MP4 playback, so the result is engine behaviour, not a claim. The POST to /result is optional and fails harmlessly on a plain static server; read the output on the page.
